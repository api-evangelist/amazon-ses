Rich Communication Services (RCS) brings branding, rich media, and verified sender identity to your customers' native messaging app. This walkthrough shows how to create, register, and test an RCS agent on AWS End User Messaging entirely from the AWS CLI, from brand assets to verified inbound messaging with an automatic keyword response.
